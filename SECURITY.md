# Security Policy / Güvenlik Politikası

**EN** — Please report vulnerabilities privately with GitHub's **“Report a vulnerability”** button (Security tab → Advisories) instead of opening a public issue. Details are on the site: `legal.html#security`. Scope: this static website only.

**TR** — Güvenlik açıklarını herkese açık bir issue yerine GitHub'ın **“Report a vulnerability”** düğmesiyle (Security sekmesi → Advisories) özel olarak bildirin. Ayrıntılar sitede: `legal.html#security`. Kapsam: yalnızca bu statik web sitesi.
